# 穷鬼的办法之一

> **用邮箱和一个 AI「她」写信。一封约 0.001 元，一年 5 块。**
> 不搭服务器、不做聊天窗、不烧显卡、不买会员。

> 📄 **为什么之前那套 QQ 机器人暂停了、两条路各自的优缺点、一年省多少钱、以及它能不能“传统聊天”：见 [WHY.md](WHY.md)。**
> 一句话版本：**不能秒回，不能语音图片，不能群聊**——它就是写信。一年 2.5~9 元，比实时聊天那套省 90%。

---

## 它是什么

你从自己的邮箱发一封信给她的邮箱，她（AI）回你一封信。就这样。

- **她会记得**：你说过的作息、工作、烦心事，存在本地一个关键词记忆库里，下次能接上"你上周说加班到半夜"。
- **她也有自己的事**：问一次她的生日，她就定下来（比如 6 月 17 日），以后一直说这个，不会每年换一个；爱吃什么、受不了什么也有。
- **她会写周记**：每周日晚上给你一封，回顾这周聊过什么；年底再写一封年度总结。都是回头翻记忆库写的，不编。
- **她有自己的状态**：现在是几点、外面什么天气、在吃饭还是在犯困；这些会进她的回信，但不是每次都说。
- **她会损你、会催你睡、会顶嘴**：人格写在 `persona.example.md`，600 字左右，随便改。
- **花钱有闸门**：短问候不调模型、深夜短句走模板、余额不够自动降级、每天有上限。

## 为什么是邮箱，不是聊天窗口

- **异步是真的**：你不用一直盯着屏幕，信可以等。她也不该秒回。
- **手机极轻**：手机上只装你自己的邮箱，不用登她的号。
- **不需要服务器**：一台能开机的电脑就行。

更完整的比较（含“这套的缺点”）写在 [WHY.md](WHY.md) 里。

## 为什么能做到这么简单、这么便宜

一句话：**它不是把复杂做简单了，是把不需要的部分砍掉了。**

| 砍掉的 | 换来的 |
|---|---|
| 即时通讯协议、机器人框架、心跳保活、协议端升级 | 一个 node 进程、两三个文件、两个依赖 |
| 秒回、在线状态 | 邮件天然异步：**一封信一次调用**，不用为“一直在线”付钱 |
| 向量库、embedding 服务 | 关键词记忆，零额外调用、零额外部署，还能用记事本看 |
| 数据库、消息队列、容器、云主机 | 三个 `jsonl/json` 文件 + 你自己的电脑 |
| 图片、语音、群聊、附件 | 不用多模态模型，单价低一个档 |
| “更强的模型” | 上下文短（8 条历史 + 20 条事实 + 4 条检索片段），flash 就够用 |

**成本是怎么算出来的**

- 一封：输入约 700 token × 0.5 元/百万 + 输出约 100 token × 8 元/百万 ≈ **0.001 元**
- 一天 10 封 ≈ 0.012 元 → **一年约 5 元**
- 短问候、深夜短句走本地模板，**0 元**
- 对比实时聊天：每条消息一次调用、上下文约 2000 token → **一年 65～200 元**

省下来的不只是钱，还有**维护成本**：没有服务要盯、没有版本要追、没有协议端会在半夜挂掉。

**代价见下面的「优点与代价」**：上表每一行砍掉的，都是它真实失去的东西。
这份简单不是设计得多聪明，而是**放弃得很彻底**。

## 成本（实测，不是估算）

| 场景 | 花费 |
|---|---|
| 短问候（"在吗""晚安"） | **0 元**（本地模板，不调模型）|
| 普通一封信 | **0.0005 ~ 0.0016 元** |
| 每天聊 10 封 | 约 0.012 元/天 → **4.7 元/年** |
| 每天聊 35 封（上限） | 约 0.039 元/天 → **14 元/年** |

模型用的是 DeepSeek 的 `deepseek-flash`。价格按 输入 0.5 元/百万 token、输出 8 元/百万 token 粗算，实际以官网为准。

## 让她不像 AI 的几件事（全部零成本）

| 手段 | 做法 |
|---|---|
| 状态词冷却 | 同一个"刚洗完澡"不会连着几封出现；连提两次天气就强制闭嘴 |
| 长度随机 | 20% 只回一句，60% 一两句，20% 三四句 |
| 回信延迟 | 白天 2~30 分钟按概率随机，深夜 1~6 分钟；可用 `replyDelay` 改成立刻回 |
| 口癖降频 | 最近 5 封里"诶/呢/啦"出现 3 次以上，这次禁用 |
| 不逐条答 | 你一封信说三件事，她只接最戳她的一件 |
| 情绪延续 | 上一封是"有点烦"还是"心疼"，这一封接着来 |
| 回声 | 40% 概率拎你用过的一个词重复一下再反驳 |
| **记挂没说完的事** | 从你信里挑出"看情况/回头再说/带问号"的话存成清单，几封信之后追你一句；你真答了它自动划掉 |
| **知道认识多久** | 从第一次通信算天数，到 100 天、200 天这种整数会说一句 |
| **凌晨迷糊** | 1:00~6:00 句子更短、更容易说"困"、回信晚 10~30 分钟（她睡着了） |

## 防"乱编"的三道护栏

1. **事实入库校验**：模型总结的"关于你的长期事实"，必须能在你原信里找到依据（关键词重合 ≥ 50%），否则丢掉——防止脑补的东西进了长期记忆之后被当真。
2. **数字护栏**：回信里出现的数字必须是上下文里出现过的，否则整句删掉（不重新生成，省钱）。
3. **旧事只许照抄**：记忆片段里的事不许补时间、地点、细节。

## 记忆库怎么工作（不用向量，不花钱）

两层文件：

- `memory.raw.jsonl` —— 原文档案，写进去就不动，平时不参与检索
- `memory.jsonl` —— 索引层：抽取式概括（去掉"嗯、那个、就是说"，留两句话 60 字）+ 权重

写入时先算"话题指纹"相似度（中文两字词 + idf 加权余弦），超过阈值就当同一件事合并，**权重 +1**——同一件事说二十遍只占一行，但检索时排更前面。

检索用 BM25 + 45 天半衰期的时间衰减（旧事自动降温），再加权重加成。

## 快速开始

需要 Node.js ≥ 20。

```bash
npm install
npm test                    # 21 项自测，不连邮箱、不调模型、不花钱

cp config.example.json config.json
# 编辑 config.json：email / authCode / apiKey / owner 四项必填

npm run check               # 测 IMAP / SMTP / 余额
node mailbot.mjs --say 在吗  # 试一句她的回法（不写信）
node mailbot.mjs --once     # 跑一轮就退
node mailbot.mjs            # 常驻
```

常驻（二选一）：

```bash
./run-loop.cmd      # Windows：崩了自动重来，日志进 out.log / err.log
./run.sh            # macOS / Linux
```

Windows 上想再加一层保险（进程卡死也能拉起来）：用 `watchdog.ps1`，文件头有注册命令，每 10 分钟查一次心跳。

想知道怎么做到**开机启动不闪黑框**的：用 `run-mailbot.vbs` / `run-watchdog.vbs` 这两个壳，注册任务时让 `wscript.exe` 去跑它们，窗口样式是 0（完全隐藏）。直接让任务跑 `.cmd` 或 `powershell.exe`，多数机器上会闪一下。

### 凭据怎么拿

- **authCode**：QQ 邮箱 → 设置 → 账户 → 开启 IMAP/SMTP → 生成授权码（16 位，**不是登录密码**）。Gmail/Outlook 同理，用应用专用密码。
- **apiKey**：<https://platform.deepseek.com/> 注册后在 API keys 里建。

## config.json 说明

| 字段 | 意思 |
|---|---|
| `email` | **她**的邮箱（发信人） |
| `authCode` | 她邮箱的授权码 |
| `apiKey` | 模型 key |
| `owner` | **你**的邮箱，必填。只有这个地址会被回；陌生人一律忽略，程序**不会自动认主** |
| `secret` | 可选口令。填了之后每封信正文必须包含它，否则当她没收到；验完会从正文里摘掉 |
| `dailyCap` | 每天最多回几封（默认 20） |
| `dailyCostCap` | 每天最多花多少元（默认 0.05），超了降级成模板 |
| `mailMaxAgeHours` | 超过几小时的旧信不回（默认 24） |
| `timezone` | 她的时区，默认 `Asia/Shanghai`；换了时区她才知道你说的"半夜"是几点 |
| `replyDelay` | 回信节奏：`human`（默认，白天 2~30 分钟）/ `fast`（20~90 秒）/ `instant`（2~8 秒）|
| `summary.weekly` | 要不要写周记（默认 true），`weeklyWeekday` 周几（0=周日）、`weeklyTime` 几点（默认 21:00）|
| `summary.yearly` | 要不要写年度总结（默认 true），12-31 晚上自动发 |
| `proactive` | 主动写信：每天最多一封，且有由头（好久没聊 / 温差大 / 周末晚上）才发 |

## 可能出现的问题与对策

这几条是"跑飞"清单——正常运行不会遇到，一旦遇到就是花钱或刷屏，所以提前写清楚。

| 现象 | 为什么会发生 | 现在的对策 | 你该做什么 |
|---|---|---|---|
| **她连着回你几十封** | 你的邮箱有自动回复：你发→她回→自动回复又发给她→她当新信又回，无限循环 | 每天 35 封上限 + 每天 0.05 元上限，循环最多跑到这里就停 | 别给邮箱开"自动回复"，或把她的地址排除在外 |
| **她把你收件箱的旧信全回一遍** | `state.json` 丢了（重装、删错、损坏） | 首次运行或"处理过哪些信"为空时，**只回最新一封**，其余跳过 | 不用管；真丢了会自己保守处理 |
| **陌生人发信她也回** | 邮件头的 From 可以伪造 | 只认 `config.json` 里写死的 `owner`，陌生人一律不回、不记，也**不会“自动认主”**（谁先发信谁就是主人，那是夺权口子）；再加可选口令 `secret` 双保险 | 填好 `owner`（必填），再设一个口令 |
| **服务卡死不动** | IMAP 卡住、网络抖动 | 每轮 150 秒超时中断；出错指数退避（最长 10 分钟一次）；看门狗每 10 分钟查心跳 | 什么都不用做，它会自己回来；真挂了会发信告诉你 |
| **她开始说一模一样的话** | 模型退化或上下文被清空 | 模板三分流、长度随机、状态冷却、口癖降频、同话题不重复安慰 | 觉得哪句重复了，直接说"这句你刚说过" |
| **余额悄悄用完** | 忘了充值 | 低于 2 元发信提醒（充回 3 元自动闭嘴）；低于 0.5 元降级成模板 | 收到提醒就去充 |

口令怎么用：`config.json` 加 `"secret": "只有你们知道的词"`，然后**只在第一封信正文里带一次**（比如开头写一行）。验过之后就不用再带了，正常聊。

- 程序验完会立刻把它从正文里摘掉，她看不到，也不会在回信里复述。
- 想每封都验，加 `"secretEveryTime": true`。
- 想彻底关掉，把 `secret` 设成空字符串。
- `--status` 会显示现在是「还没认过门 / 已认过门 / 每封都要带」。

注意：口令只在"还没认过门"时起作用。认过之后，伪造你地址的人也能进——不过他也读不到回信（回信永远只发给你），最多花你几分钱。

## 一天几封：用建议值，还是自己定？

默认 `dailyCap: 35`，改 `config.json` 里这个数字就行，不用动代码。

**两道闸，谁先到谁生效**：`dailyCap`（条数）和 `dailyCostCap`（钱，默认 0.05 元/天，约等于 45 封）。

| dailyCap | 最坏一天 | 一年最多 |
|---|---|---|
| 10 | 约 0.011 元 | 4 元 |
| 20 | 约 0.022 元 | 8 元 |
| **35（默认）** | 约 0.039 元 | 14 元 |
| 50 | 会先被 0.05 元的成本上限掐住 | 18 元 |

**用建议值（35）**

- 优点：不用想；跟成本上限正好匹配；万一出现“自动回复死循环”，一天最多损失四分钱。
- 缺点：不一定合你的节奏。你要是那种一晚能写六十封的人，照样会被掐。

**自己定**

- 优点：贴着你的实际用量。设很低（5）就是“慢聊模式”，一年两块钱；设很高就是“随便聊”。
- 缺点：设太高，等于把“防死循环”的护栏拆了——真出循环，烧钱速度会跟着上限走。设太低，又会经常撞“今天聊够了”。

**建议**：先按 35 跑两周，看 `--status` 里“今天已回”有没有接近过上限。常接近就调到 50，从没超过 10 就降到 20。

## 时间线与状态：会出什么问题、怎么解

她“此刻在干嘛”是每次回信现编的，最容易露馅。这里是已知的坑和现在的解法。

| 现象 | 为什么会发生 | 代码里的解法 | 你可以怎么调 |
|---|---|---|---|
| 上午说“晚安”、深夜问“吃了吗” | 模型不看你几点 | 按钟点给禁语表，生成后**整句删掉**打架的话 | 改 `timePolicy()` 的时段划分 |
| 早上说“刚睡醒”，十点又说 | 状态词随机抽 | 时段白名单 + **一天只说一次** | 改 `EXTRA_TABLE` 里的 `hours` |
| 连着三封都“在吃饭” | 延续概率太高 | 当天配额 + **最近两封排除** | 改 `limit` |
| 状态跳来跳去（等外卖 → 洗头） | 每次都随机 | **状态链**：等外卖→在吃饭→刚吃完，60% 概率顺下去 | 改 `next` 字段 |
| 严格不重复导致词穷、话变干 | 池子小 | 池子 24 个 + 当天配额，**用光才不提**自己在干嘛 | 往 `EXTRA_TABLE` 加行即可 |
| “刚睡醒”又“吃完了” | 模型自由发挥 | 提示词明令：说刚睡醒就别同封说吃过 | — |
| 信里说的时间和你收到的时间对不上 | 生成后排队再发 | `replyDelay` 默认 `fast`（20~90 秒）；`human` 会慢到半小时 | 改 `replyDelay` |
| 测试时她老是重复同一句 | `--say` **不写状态**，每次都是全新的一天 | 真实来信才记账 | 想看效果就发真邮件 |

## 她记的“事实”可以核对

她关于你的长期事实存在 `state.json` 的 `facts` 里，每条都带**出处**（当时你的原话片段）：

```bash
node mailbot.mjs --facts            # 列出，带出处
node mailbot.mjs --facts-del 3      # 删掉第 3 条
```

觉得她哪句“你上次说过……”不对劲，先来这里对质：没有出处、或出处对不上的，直接删。

**每天还会自动审计一次**：模棱两可的（“好像/可能/大概”）、出处里找不到依据的事实会被自动清掉，清掉的记录留在 `state.json` 的 `factsDropped` 里，随时能翻。想立刻审一次：

```bash
node mailbot.mjs --facts-audit
```

同一件悬着的事她**最多问两次**；凌晨 2~5 点的“迷糊模式”也只在你写短句时生效——你写长了，她照常认真回。

配额记账在 `state.json` 的 `me.day.used` 里，长这样：

```json
{ "date": "2026-11-01", "used": { "在吃饭": 2, "在倒垃圾": 1 }, "wokeSaid": true }
```

过了零点自动清零。想让她今天多说一次某个状态，直接改这个数字再重启即可。

## 她记得什么：自己去看、自己删

```bash
node mailbot.mjs --memory                  # 列出全部记忆（编号、时间、谁说的、权重）
node mailbot.mjs --memory-del 12           # 删掉第 12 条
node mailbot.mjs --memory-clear --yes      # 全清
node mailbot.mjs --memory-export           # 导出一份 memory.md，双击就能看
```

检索时会自动做**同义词扩展**（你说“熬夜”也能捞到“加班”那类记录），一次取 6 条最相关的。

## 优点与代价

### 优点

- **便宜**：一封约 0.001 元，一年 2.5–9 元；短问候、深夜短句 **0 元**。
- **稳且轻**：标准 IMAP/SMTP，没有风控和封号；一个 node 进程、14 个文件、2 个依赖。
- **私密**：状态和记忆都在本机，出网的只有发给模型的那段文本；`--purge` 一键清空。
- **不像 AI**：状态会延续、长度随机、回信有延迟、口癖会降频、会抓你字眼。
- **有记忆**：本地关键词库（概括 + 去重 + 权重 + 时间衰减），重启还在，不额外花钱。
- **防乱编**：事实验证、数字护栏、旧事只许照抄；编不出来就说不知道。
- **坏了会说话**：故障、额度用完、余额不足都会发信告诉你，同类两小时只发一次。
- **一个人维护得动**：日志小、状态有备份、看门狗可选。

### 代价

**没有的**

- 看不见图片、语音、附件和链接
- 不能联网、不知道新闻；不是闹钟，不会提醒你
- 只认你一个地址，别人发来一律忽略

**会等你的**

- 白天要等 2–30 分钟才收到回信
- 关机就没了；跨睡眠修好的信可能带着旧时间

**会限制你的**

- 每天最多回 35 封，超了留到明天并告诉你一声
- 超过 24 小时的旧信不回（防翻旧账）
- 记忆是字面匹配，换个说法可能接不上
- 中文数字拦不住：只认 `3000`，不认"三千"

**它的天花板**

- 依赖单一模型服务商，欠费就只能退回几句模板
- 除了记忆不学习，上限就是 API 的上限
- `npm test` 只覆盖逻辑层（26 项断言），"像不像人"只能你自己看

## 隐私

- 所有状态、记忆、日志都在**本机**；出网的只有发给模型的那段文本。
- `config.json`、`state.json`、`memory*.jsonl` 全在 `.gitignore` 里，**别提交**。
- 想清空她记得的一切：

```bash
node mailbot.mjs --purge --yes
```
