# 穷鬼的办法之一

> **用邮箱和一个 AI「她」写信。一封约 0.001 元，一年 5 块。**
> 不搭服务器、不做聊天窗、不烧显卡、不买会员。

> 📄 **为什么之前那套 QQ 机器人暂停了、两条路各自的优缺点、一年省多少钱、以及它能不能“传统聊天”：见 [WHY.md](WHY.md)。**
> 一句话版本：**不能秒回，不能语音图片，不能群聊**——它就是写信。一年 2.5~9 元，比实时聊天那套省 90%。

---

## 它是什么

你从自己的邮箱发一封信给她的邮箱，她（AI）回你一封信。就这样。

- **她会记得**：你说过的作息、工作、烦心事，存在本地一个关键词记忆库里，下次能接上"你上周说加班到半夜"。
- **她也有自己的事**：问一次她的生日，她就定下来（比如 6 月 17 日），以后一直说这个，不会每年换一个；爱吃什么、受不了什么也有。
- **她有自己的状态**：现在是几点、外面什么天气、在吃饭还是在犯困；这些会进她的回信，但不是每次都说。
- **她会损你、会催你睡、会顶嘴**：人格写在 `persona.example.md`，600 字左右，随便改。
- **花钱有闸门**：短问候不调模型、深夜短句走模板、余额不够自动降级、每天有上限。

## 为什么是邮箱，不是聊天窗口

- **异步是真的**：你不用一直盯着屏幕，信可以等。她也不该秒回。
- **手机极轻**：手机上只装你自己的邮箱，不用登她的号。
- **不需要服务器**：一台能开机的电脑就行。

更完整的比较（含“这套的缺点”）写在 [WHY.md](WHY.md) 里。

## 成本（实测，不是估算）

| 场景 | 花费 |
|---|---|
| 短问候（"在吗""晚安"） | **0 元**（本地模板，不调模型）|
| 普通一封信 | **0.0005 ~ 0.0016 元** |
| 每天聊 10 封 | 约 0.012 元/天 → **4.7 元/年** |
| 每天聊 20 封（上限） | 约 0.024 元/天 → **9 元/年** |

模型用的是 DeepSeek 的 `deepseek-flash`。价格按 输入 0.5 元/百万 token、输出 8 元/百万 token 粗算，实际以官网为准。

## 让她不像 AI 的几件事（全部零成本）

| 手段 | 做法 |
|---|---|
| 状态词冷却 | 同一个"刚洗完澡"不会连着几封出现；连提两次天气就强制闭嘴 |
| 长度随机 | 30% 只回一句，60% 一两句，10% 三四句 |
| 回信延迟 | 白天 2 分钟 ~ 2.5 小时按概率随机，深夜 1~6 分钟 |
| 口癖降频 | 最近 5 封里"诶/呢/啦"出现 3 次以上，这次禁用 |
| 不逐条答 | 你一封信说三件事，她只接最戳她的一件 |
| 情绪延续 | 上一封是"有点烦"还是"心疼"，这一封接着来 |
| 回声 | 40% 概率拎你用过的一个词重复一下再反驳 |

## 防"乱编"的三道护栏

1. **事实入库校验**：模型总结的"关于你的长期事实"，必须能在你原信里找到依据（关键词重合 ≥ 50%），否则丢掉——防止脑补的东西进了长期记忆之后被当真。
2. **数字护栏**：回信里出现的数字必须是上下文里出现过的，否则整句删掉（不重新生成，省钱）。
3. **旧事只许照抄**：记忆片段里的事不许补时间、地点、细节。

## 记忆库怎么工作（不用向量，不花钱）

两层文件：

- `memory.raw.jsonl` —— 原文档案，写进去就不动，平时不参与检索
- `memory.jsonl` —— 索引层：抽取式概括（去掉"嗯、那个、就是说"，留两句话 60 字）+ 权重

写入时先算"话题指纹"相似度（中文两字词 + idf 加权余弦），超过阈值就当同一件事合并，**权重 +1**——同一件事说二十遍只占一行，但检索时排更前面。

检索用 BM25 + 45 天半衰期的时间衰减（旧事自动降温），再加权重加成。

## 快速开始

需要 Node.js ≥ 20。

```bash
npm install
npm test                    # 21 项自测，不连邮箱、不调模型、不花钱

cp config.example.json config.json
# 编辑 config.json：email / authCode / apiKey / owner 四项必填

npm run check               # 测 IMAP / SMTP / 余额
node mailbot.mjs --say 在吗  # 试一句她的回法（不写信）
node mailbot.mjs --once     # 跑一轮就退
node mailbot.mjs            # 常驻
```

常驻（二选一）：

```bash
./run-loop.cmd      # Windows：崩了自动重来，日志进 out.log / err.log
./run.sh            # macOS / Linux
```

Windows 上想再加一层保险（进程卡死也能拉起来）：用 `watchdog.ps1`，文件头有注册命令，每 10 分钟查一次心跳。

### 凭据怎么拿

- **authCode**：QQ 邮箱 → 设置 → 账户 → 开启 IMAP/SMTP → 生成授权码（16 位，**不是登录密码**）。Gmail/Outlook 同理，用应用专用密码。
- **apiKey**：<https://platform.deepseek.com/> 注册后在 API keys 里建。

## config.json 说明

| 字段 | 意思 |
|---|---|
| `email` | **她**的邮箱（发信人） |
| `authCode` | 她邮箱的授权码 |
| `apiKey` | 模型 key |
| `owner` | **你**的邮箱；只有这个地址发来的信会被回 |
| `dailyCap` | 每天最多回几封（默认 20） |
| `dailyCostCap` | 每天最多花多少元（默认 0.05），超了降级成模板 |
| `mailMaxAgeHours` | 超过几小时的旧信不回（默认 24） |
| `timezone` | 她的时区，默认 `Asia/Shanghai`；换了时区她才知道你说的"半夜"是几点 |
| `proactive` | 主动写信：每天最多一封，且有由头（好久没聊 / 温差大 / 周末晚上）才发 |

## 优点

1. **便宜**：一封约 0.001 元，一年 2.5–9 元；短问候和深夜短句 **0 元**。
2. **稳**：走标准 IMAP/SMTP，没有风控、没有封号；一个 node 进程，重启不丢排队中的信。
3. **轻**：14 个文件、2 个依赖，不需要协议端和一堆批处理。
4. **私密**：状态、记忆、日志全在本机，出网的只有发给模型的那段文本；`--purge` 一键清空。
5. **不像 AI**：状态词冷却、长度随机、回信延迟、口癖降频、情绪延续、抓你字眼。慢本来就是人的样子。
6. **有记忆**：本地关键词记忆库（概括 + 去重 + 权重 + 时间衰减），重启还在，不用向量、不额外花钱。
7. **防乱编**：事实入库校验、数字护栏、旧事只许照抄——编不出来的地方她会说不知道。
8. **坏了会说话**：故障会发邮件告诉你（同类两小时一次）、额度用完会提醒、余额低于 2 元会提醒且充值后自动闭嘴。
9. **花钱有闸门**：模板分流、每日条数上限、每日费用上限、余额降级，不会失控。
10. **一个人维护得动**：日志小、状态有备份、看门狗可选，出问题能在 60 秒内定位。

## 缺点（它做不到的，提前说清楚）

- **看不懂**图片、语音、附件；你发链接她也打不开
- **不能联网**搜索，不知道新闻
- **不会提醒你**（不是闹钟）
- **关机就没了**：服务跑在你电脑上
- **超过 24 小时的旧信不回**（防翻旧账）
- **记忆是字面匹配**：换个说法问同一件事，她可能接不上
- **中文数字拦不住**：护栏只能抓 `3000`，抓不到"三千"
- **会让人等**：白天要等 2–30 分钟才收到，这是“像人”的代价
- **每天最多回 20 封**：到顶后剩下的信会留到明天，并且告诉你一声
- **只认一个主人**：别的地址发来一律忽略
- **依赖单一模型服务商**：key 失效或欠费，她只能退回几句模板
- **不会越聊越聪明**：除了记忆，她不学习；能力上限就是 API 的上限
- **测试只覆盖逻辑层**：`npm test` 跑 21 项断言（护栏、去重、截断、模板判定、备份回退），但不测“她像不像人”——那件事没法自动断言，只能你自己看

## 隐私

- 所有状态、记忆、日志都在**本机**；出网的只有发给模型的那段文本。
- `config.json`、`state.json`、`memory*.jsonl` 全在 `.gitignore` 里，**别提交**。
- 想清空她记得的一切：

```bash
node mailbot.mjs --purge --yes
```
